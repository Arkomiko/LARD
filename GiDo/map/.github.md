# .github/ — настройки страницы на GitHub

**Что здесь.** Служебные файлы, которые читает сам GitHub.

- `FUNDING.yml` — кнопка «Sponsor» на странице репозитория со ссылками
  на донаты: GitHub Sponsors, Boosty, DonationAlerts.

**Почему отдельная папка.** GitHub ищет такие файлы только в `.github/`.
Название папки начинается с точки — так принято для служебных папок.

**Статус.** Готово. Позже здесь могут появиться шаблоны для задач (issues).
