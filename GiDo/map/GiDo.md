# GiDo/ — все тексты проекта

**Что здесь.** GiDo означает «git and docs». Здесь лежат документация, журналы
и лицензии. В остальных папках проекта — только код, данные и ресурсы.

| Файл или папка | Что это |
| --- | --- |
| `CHANGELOG.txt` | история изменений по версиям |
| `DECISIONS.md` | журнал решений: что решили, когда и почему |
| `ARCHITECTURE.md` | как устроена программа, со схемой |
| `BUILD.md` | как собрать программу с нуля на чистой Windows |
| `DAW_SUPPORT.md` | что работает в каждой DAW и как её настроить |
| `map/` | описание каждой папки проекта → [GiDo.map.md](GiDo.map.md) |
| `licenses/` | лицензии → [GiDo.licenses.md](GiDo.licenses.md) |

Позже появятся `MODDING.md` (как писать моды, этап 8) и `MODDING_LICENSE.md`
(как лицензировать моды).

**Исключения из правила «тексты только здесь».** `README.md` и `LICENSE` лежат
в корне, потому что GitHub ищет их именно там. `.github/FUNDING.yml` лежит
в `.github/` по той же причине.
