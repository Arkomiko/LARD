# app/engine-tests/ — тесты движка

**Что здесь.** Автоматические проверки движка на xUnit. Запуск — `dotnet test`
в папке `app` или `scripts/test.ps1` для всех тестов сразу.

| Файл | Что проверяет |
| --- | --- |
| `ProjectArchiveTests.cs` | .mpj записывается и читается; сбой записи не портит старый файл; понятные ошибки |
| `AutosaveStoreTests.cs` | хранятся только последние копии; опасные номера отклоняются; старьё убирается |
| `SettingsStoreTests.cs` | значения по умолчанию из ТЗ; границы; испорченный файл не мешает запуску |
| `FileLogTests.cs` | журнал пишется, хранятся 10 последних дней, ошибки журнала не роняют программу |
| `FileNamesTests.cs` | имена файлов без запрещённых в Windows символов |
| `TemporaryFolder.cs` | временная папка для теста (не тест) |

**Почему тесты — отдельный проект.** Так тесты и их библиотека (xUnit) не
попадают в готовую программу.

Имена тестов написаны по-русски — так их проще читать в списке результатов.
