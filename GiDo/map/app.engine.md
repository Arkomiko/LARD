# app/engine/ — движок

**Что здесь.** Часть программы на C# (.NET 10), которая работает с диском.
Не зависит от Windows: на другой системе .NET подставит свои папки.

| Файл | Что внутри |
| --- | --- |
| `ProjectArchive.cs` | файл проекта .mpj: ZIP-архив с project.json — запись и чтение |
| `AtomicFile.cs` | надёжная запись: временный файл, затем подмена — старый файл не портится при сбое |
| `AutosaveStore.cs` | резервные копии: запись, сколько хранить, список, уборка старых |
| `AppSettings.cs` | настройки программы и их допустимые границы |
| `SettingsStore.cs` | чтение и запись settings.json |
| `FileLog.cs` | журнал работы: по файлу на день, хранятся последние 10 |
| `FileNames.cs` | имя файла из имени проекта (запрещённые в Windows символы → «_») |
| `AppFolders.cs` | где лежат данные программы: %APPDATA%\MiliPlain |
| `MiliPlain.Engine.csproj` | описание проекта для .NET |

**Чего здесь нет.** Модели проекта: она живёт в интерфейсе (`app/ui`).
Движок не разбирает project.json — он только кладёт текст в архив и достаёт
обратно. Окон тоже нет: окна делает `app/shell`.

**Что появится дальше.** MIDI-вход и выход, проигрывание, звук (этап 4),
связь с мостом (этап 5).

**С чем связано.** Им пользуется `app/shell`. Тесты — `app/engine-tests`.
