# app/shell/ — оболочка для Windows

**Что здесь.** Окно программы на C# (WinForms) с элементом WebView2, который
показывает интерфейс `app/ui`. Единственная часть MiliPlain, которая знает
про Windows. Собирается в **MiliPlain.exe**.

| Файл | Что внутри |
| --- | --- |
| `Program.cs` | запуск: журнал, перехват необработанных ошибок, параметры (`--ui-dev`), версия |
| `MainWindow.cs` | окно и WebView2: откуда грузить интерфейс, вопрос о несохранённом при закрытии |
| `MessageRouter.cs` | разбор просьб интерфейса и отправка ответов |
| `HostMethods.cs` | сами методы: диалоги «Открыть» и «Сохранить», запись проекта, копии, настройки |
| `ShellServices.cs` | части движка, которыми пользуется оболочка |
| `MiliPlain.Shell.csproj` | описание проекта; здесь же — копирование собранного интерфейса в папку `ui` рядом с exe |

**Откуда берётся интерфейс.**
- Обычно — из папки `ui` рядом с exe (туда копируется `app/ui/dist`).
- С параметром `--ui-dev` — с dev-сервера Vite (`http://localhost:5173`):
  правки интерфейса видны сразу, без пересборки. Так запускает `scripts/dev.ps1`.

**Почему отдельно от движка.** Чтобы перенести MiliPlain на macOS или Linux,
пишется новая оболочка под ту систему, а движок и интерфейс не меняются.
См. запись «Третья часть программы: app/shell» в [../DECISIONS.md](../DECISIONS.md).

**С чем связано.** Пользуется `app/engine`. Имена методов в `HostMethods.cs`
совпадают с `app/ui/src/host/hostApi.ts`.
