# app/ui/ — интерфейс

**Что здесь.** Всё, что пользователь видит и трогает, и модель проекта.
Это веб-страница на TypeScript, HTML и CSS, которую оболочка `app/shell`
показывает внутри окна программы.

| Папка или файл | Что это | Описание |
| --- | --- | --- |
| `src/` | исходный код интерфейса | [app.ui.src.md](app.ui.src.md) |
| `tests/` | тесты (Vitest) | [app.ui.tests.md](app.ui.tests.md) |
| `index.html` | страница, с которой всё начинается | — |
| `package.json` | список инструментов (TypeScript, Vite, Vitest, Biome) и команд | — |
| `package-lock.json` | точные версии всех пакетов — чтобы у всех собиралось одинаково | — |
| `vite.config.ts` | настройки сборки и тестов | — |
| `tsconfig.json` | настройки проверки типов TypeScript | — |
| `biome.jsonc` | правила стиля кода | — |

Папки `node_modules/` (скачанные пакеты) и `dist/` (собранный интерфейс)
создаются командами и в git не хранятся.

**Команды** (из этой папки):
- `npm install` — один раз, скачать инструменты;
- `npm test` — тесты;
- `npm run build` — собрать в `dist/` (оттуда оболочка берёт интерфейс);
- `npm run dev` — dev-сервер для режима разработки (см. `scripts/dev.ps1`);
- `npm run check` — проверить стиль кода.

**С чем связано.**
- `app/shell` загружает собранную страницу в окно и выполняет её просьбы.
- `presets/` и `mods/` — на этапах 7 и 8 отсюда будут читаться темы, языки
  и моды.
