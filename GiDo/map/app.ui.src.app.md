# app/ui/src/app/ — точка входа, действия, команды

**Что здесь.**

| Файл | Что внутри |
| --- | --- |
| `main.ts` | запуск: связывает хранилище, оболочку, автосохранение, пианоролл, команды и экран |
| `projectActions.ts` | новый, открыть, сохранить, сохранить как, резервная копия, закрытие окна |
| `commands.ts` | все команды программы по именам: `file.save`, `tool.draw`, `notes.copy`… |
| `keymap.ts` | таблица «команда — сочетание клавиш» (как в FL Studio) и перевод нажатия в сочетание |
| `hotkeys.ts` | диспетчер: нажатие → сочетание → команда |
| `strings.ts` | все надписи интерфейса |

**Горячие клавиши — три слоя (ТЗ, п. 7).**
1. Команда — имя и действие (`commands.ts`).
2. Таблица — какая клавиша вызывает какую команду (`keymap.ts`).
3. Диспетчер — читает таблицу и вызывает команду (`hotkeys.ts`).

Поэтому клавишу можно переназначить, не трогая код команды. На этапе 7
таблица будет загружаться из пресетов и редактироваться в настройках.

Клавиша определяется по месту на клавиатуре, а не по букве: P, B, D, E работают
и в русской раскладке. В поле ввода работают только команды файла (Ctrl+S
и подобные), чтобы Delete и стрелки правили текст, а не ноты.

**Почему действия отдельно от экрана.** В `projectActions.ts` и `commands.ts`
только порядок шагов, без кнопок, поэтому их проверяют тесты
(`tests/projectActions.test.ts`, `tests/hotkeys.test.ts`).

**Что временное.** Надписи на этапе 7 переедут в языковые пресеты
(`presets/languages/`).
