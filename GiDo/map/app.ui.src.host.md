# app/ui/src/host/ — связь с оболочкой

**Что здесь.**

| Файл | Что внутри |
| --- | --- |
| `shellBridge.ts` | канал сообщений WebView2: просьбы, ответы, события |
| `hostApi.ts` | список всего, что интерфейс может попросить у оболочки, с типами; заглушка для обычного браузера |

**Как это работает.** Интерфейс отправляет просьбу
`{kind: "request", id, method: "project.write", params}`. Оболочка выполняет её
и отвечает `{kind: "response", id, ok, result}`. Иногда оболочка сама
присылает событие, например `closeRequested` — «пользователь закрывает окно».

**Почему через HostApi.** Остальной код знает только список методов, а не то,
как они доставляются. Поэтому в тестах оболочку заменяет поддельная
(`tests/fakeHost.ts`), а в обычном браузере (`npm run dev` без окна MiliPlain)
— заглушка, которая честно говорит, что файлы недоступны.

**С чем связано.** Имена методов совпадают с `app/shell/HostMethods.cs` —
менять их надо в обоих местах сразу.
