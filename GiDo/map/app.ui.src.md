# app/ui/src/ — исходный код интерфейса

**Что здесь.** Код интерфейса, разложенный по обязанностям. Стрелка
означает «пользуется»: нижние папки ничего не знают о верхних.

```
app → view, pianoRoll → state → model
app → files → model
app → host
```

| Папка | Что в ней | Описание |
| --- | --- | --- |
| `model/` | из чего состоит проект, музыкальная сетка и правки | [app.ui.src.model.md](app.ui.src.model.md) |
| `state/` | хранилище: проект, история отмены, выбор, настройки редактора | [app.ui.src.state.md](app.ui.src.state.md) |
| `files/` | формат project.json, миграции, автосохранение | [app.ui.src.files.md](app.ui.src.files.md) |
| `host/` | связь с оболочкой (C#) | [app.ui.src.host.md](app.ui.src.host.md) |
| `pianoRoll/` | пианоролл: холст, инструменты, жесты, отрисовка | [app.ui.src.pianoRoll.md](app.ui.src.pianoRoll.md) |
| `view/` | остальной экран: верхняя панель, проект, каналы, паттерны, окна | [app.ui.src.view.md](app.ui.src.view.md) |
| `app/` | точка входа, действия с файлами, команды и горячие клавиши | [app.ui.src.app.md](app.ui.src.app.md) |

**Почему так.** `model`, `state` и `files` не знают ни про экран, ни про
оболочку — поэтому их целиком проверяют тесты без браузера и без окна.
Логика пианоролла (инструменты, жесты, поиск нот) тоже не зависит от холста
и проверяется тестами; к экрану привязаны только `pianoRollCanvas.ts`
и `render/`.
