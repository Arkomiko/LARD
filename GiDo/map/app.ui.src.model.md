# app/ui/src/model/ — модель проекта

**Что здесь.** Из чего состоит проект (ТЗ, п. 6.1) и функции, которые его правят.

| Файл | Что внутри |
| --- | --- |
| `types.ts` | проект, канал, паттерн, нота и их границы (высота 0…127, velocity 1…127, 16 цветов…) |
| `create.ts` | создание новых объектов и приведение ноты к допустимым значениям |
| `projectEdits.ts` | имя, темп, размер |
| `channelEdits.ts` | каналы: добавить, переименовать, MIDI-канал, удалить |
| `patternEdits.ts` | паттерны: добавить, переименовать, удалить |
| `noteEdits.ts` | ноты: добавить, изменить, удалить — сразу группой |
| `noteGroupEdits.ts` | группа нот как целое: сдвинуть, растянуть, квантизовать |
| `timeGrid.ts` | музыкальная сетка: тики в доле и такте, варианты привязки, прижать к сетке |
| `listHelpers.ts` | замена элемента списка без изменения остальных |
| `limits.ts` | приведение чисел к границам |

**Главное правило.** Объекты модели неизменяемые. Каждая функция правки
принимает проект и возвращает **новый**, а старый остаётся как был. Если
правка ничего не меняет, возвращается тот же объект. Благодаря этому:
- история отмены — это просто список прошлых версий (`state/`);
- «изменилось ли что-то» проверяется сравнением ссылок (`===`);
- «есть ли несохранённое» — сравнением текущей версии с сохранённой.

**Сетка.** Доля зависит от размера: в 4/4 доля — четверть (960 тиков),
в 6/8 — восьмая (480). Привязка «1/4 доли» — это «шаг» (step) FL Studio.

**С чем связано.** Ничего не импортирует извне. Модель используют `state/`,
`files/`, `pianoRoll/` и `view/`; на этапе 8 через API её будут править моды.

**Тесты:** `tests/model.test.ts`, `tests/timeGrid.test.ts`.
