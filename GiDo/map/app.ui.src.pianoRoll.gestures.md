# app/ui/src/pianoRoll/gestures/ — жесты мышью

**Что здесь.** Жест — действие от нажатия кнопки мыши до её отпускания.
Инструменты (`tools/`) решают, какой жест начать, а сами жесты лежат здесь,
чтобы разные инструменты пользовались одними и теми же.

| Файл | Жесты |
| --- | --- |
| `drawAndErase.ts` | поставить ноту и сразу тянуть (LARD, левая кнопка); стереть протяжкой (LARD, правая кнопка); нарисовать ряд нот кистью |
| `moveAndResize.ts` | перетащить ноту или выделенную группу; растянуть за правый край |
| `boxSelect.ts` | выделение рамкой |

**Главное правило.** Каждый жест, который меняет проект, — **один шаг истории
отмены**: жест вызывает `store.beginGesture` при нажатии и `store.endGesture`
при отпускании. Поставить ноту и протащить её через полэкрана — один Ctrl+Z.
Esc во время жеста (`cancel`) возвращает всё как было.

**Почему смещения считаются от исходных нот.** При каждом движении мыши жест
заново применяет полное смещение к положению нот на момент нажатия. Если
прибавлять по чуть-чуть к текущему положению, округления копились бы и ноты
«уплывали» бы.

**Тесты:** `tests/tools.test.ts`.
