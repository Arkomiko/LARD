# app/ui/src/pianoRoll/ — пианоролл

**Что здесь.** Пианоролл с методом LARD (ТЗ, п. 6.2): сетка, ноты, клавиатура,
линейка тактов, инструменты Draw, Paint, Delete, Select, выделение,
перемещение, растягивание, квантизация, копирование и вставка.

| Файл или папка | Что внутри |
| --- | --- |
| `pianoRollPanel.ts` | панель: строка инструментов (инструменты, привязка, квантизация) и холст |
| `pianoRollCanvas.ts` | холст: рисует кадр и передаёт нажатия мыши инструменту; колесо — прокрутка и масштаб |
| `viewport.ts` | окно просмотра: какой кусок сетки виден, перевод пикселей в тики и высоты нот |
| `hitTest.ts` | какая нота под курсором, какие ноты попали в рамку или под ластик |
| `noteCommands.ts` | команды над выделением: удалить, копировать, вставить, дублировать, транспонировать, сдвинуть, квантизовать |
| `tools/` | инструменты → [app.ui.src.pianoRoll.tools.md](app.ui.src.pianoRoll.tools.md) |
| `gestures/` | жесты мышью → [app.ui.src.pianoRoll.gestures.md](app.ui.src.pianoRoll.gestures.md) |
| `render/` | рисование → [app.ui.src.pianoRoll.render.md](app.ui.src.pianoRoll.render.md) |
| `testNotes.ts` | временная кнопка «Тест: 5000 нот» для проверки скорости |
| `developerTools.ts` | замер скорости — только в режиме разработки, в программу не попадает |

**Как это работает.** Нажатие мыши → `pianoRollCanvas` спрашивает текущий
инструмент (`tools/`), что делать → инструмент запускает жест (`gestures/`) →
жест правит проект через хранилище (`store.edit`) → хранилище оповещает →
холст рисует новый кадр (`render/`). Рисуется не на каждую правку, а один раз
за кадр экрана.

**Какие ноты видны.** Только ноты выбранного канала в открытом паттерне —
как в FL Studio. Ноты других каналов появятся как ghost-ноты на этапе 6.

**С чем связано.** Состояние берёт из `state/` (проект, выделение, инструмент,
привязка), правит проект функциями из `model/`. Горячие клавиши приходят через
команды (`app/commands.ts`).

**Тесты:** `tests/tools.test.ts`, `tests/viewport.test.ts`, `tests/noteCommands.test.ts`.
