# app/ui/src/pianoRoll/render/ — рисование пианоролла

**Что здесь.** Функции, которые рисуют кадр пианоролла на холсте (Canvas 2D).

| Файл | Что рисует |
| --- | --- |
| `drawGrid.ts` | фон: полосы чёрных клавиш, границы октав, линии шагов, долей и тактов |
| `drawNotes.ts` | ноты: заливка по цветам, заглушённые полупрозрачно, обводка, выделение, подписи |
| `drawFrame.ts` | клавиатура слева, линейка тактов сверху, рамка выделения |
| `palette.ts` | цвета из дизайн-токенов (`styles.css`) |

**Порядок кадра:** фон → ноты → рамка выделения → клавиатура → линейка.

**Почему так быстро на 5000 нот** (ТЗ, п. 4):
- рисуются только видимые ноты;
- ноты одного цвета складываются в один путь и заливаются одним вызовом;
- обводка и подписи — только в крупном масштабе, где их видно;
- линии сетки, которые слиплись бы в серое пятно, не рисуются.

Замеры — в записи «Пианоролл и показатели раздела 4» в
[../DECISIONS.md](../DECISIONS.md).

**Цвета** берутся из CSS-переменных `--roll-*` и `--note-color-1…16`.
Тема на этапе 7 поменяет их, не трогая этот код.
