# app/ui/src/pianoRoll/tools/ — инструменты пианоролла

**Что здесь.**

| Файл | Что внутри |
| --- | --- |
| `tools.ts` | четыре инструмента: что делает каждый при нажатии и какой показывать курсор |
| `toolTypes.ts` | общие типы: положение мыши, жест, инструмент; привязка с учётом Alt |

**Инструменты** (клавиши по умолчанию — как в FL Studio):

| Инструмент | Клавиша | Левая кнопка |
| --- | --- | --- |
| Draw (карандаш) | P | по пустому — поставить ноту и сразу тянуть (метод LARD); по ноте — двигать; за правый край — растягивать |
| Paint (кисть) | B | как Draw, но протяжка по пустому месту рисует ряд нот |
| Delete (ластик) | D | стирать |
| Select (выделение) | E | по пустому — рамка; по ноте — выделить и двигать; Shift/Ctrl — добавить к выделению |

**Во всех инструментах:** правая кнопка стирает (зажатая — протяжкой), Ctrl +
протяжка рисует рамку выделения, зажатый Alt временно отключает привязку
к сетке.

**Как добавить инструмент** (Mute, Slice, Zoom — этап 6): описать новый объект
`Tool` в `tools.ts`, добавить его имя в `TOOL_NAMES` (`state/editorPreferences.ts`)
и клавишу в `app/keymap.ts`.

**Тесты:** `tests/tools.test.ts` — каждый инструмент проверяется как
последовательность «нажал — повёл — отпустил».
