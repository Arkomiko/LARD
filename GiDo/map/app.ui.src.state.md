# app/ui/src/state/ — состояние и история отмены

**Что здесь.**

| Файл | Что внутри |
| --- | --- |
| `projectStore.ts` | хранилище: открытый проект, выбор, настройки редактора, путь к файлу, «есть несохранённое» |
| `undoHistory.ts` | история отмены: стопки прошлых и отменённых версий, лимит шагов (по умолчанию 100) |
| `editorSelection.ts` | выбор: открытый паттерн, выбранный канал, выделенные ноты; что делать, если выбранное исчезло |
| `editorPreferences.ts` | настройки редактора: инструмент, привязка к сетке, длина, сила и цвет новой ноты |

**Как этим пользоваться.** Проект меняется только через хранилище:

```ts
store.edit("Добавить ноту", (project) => addNotes(project, patternId, [note]));
```

Хранилище применяет правку, пишет шаг в историю и один раз оповещает
подписчиков (экран перерисовывается). Для перетаскивания есть «жесты»:
`beginGesture` → много `edit` → `endGesture` дают один шаг истории.

**Что в историю не попадает.** Выбор (паттерн, канал, выделенные ноты)
и настройки редактора (инструмент, привязка) — это не правки проекта.
Правка и выбор могут применяться вместе, одной транзакцией: вставленные ноты
сразу выделяются (урок LARD про мигание).

**Что видит пианоролл.** `store.editableNotes` — ноты выбранного канала
в открытом паттерне. Выделить можно только их.

**Тесты:** `tests/projectStore.test.ts`, `tests/undoHistory.test.ts`.
