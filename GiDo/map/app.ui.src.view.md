# app/ui/src/view/ — экран (кроме пианоролла)

**Что здесь.** Верхняя панель команд, левая панель с проектом, каналами
и паттернами, окна настроек и резервных копий, уведомления. Пианоролл живёт
в своей папке `pianoRoll/`. Раскладку «паттерны — каналы — пианоролл»
из ТЗ сделает этап 3, а настоящий дизайн — этап 7.

| Файл | Что внутри |
| --- | --- |
| `appView.ts` | раскладка окна; панели перерисовываются, только когда меняется то, что они показывают |
| `toolbar.ts` | верхняя панель: файл, отмена/повтор, копии, настройки |
| `projectPanel.ts` | левая панель: проект, каналы, паттерны |
| `settingsDialog.ts` | окно настроек |
| `backupsDialog.ts` | окно резервных копий |
| `notices.ts` | уведомления в углу |
| `musicText.ts` | «C4» вместо 60, «1.1.0» вместо тиков |
| `dom.ts` | помощники для построения страницы |
| `viewContext.ts` | что получают все части экрана |
| `styles.css` | оформление на дизайн-токенах, включая цвета пианоролла и 16 цветов нот |

**Почему панели перерисовываются не всегда.** При перетаскивании ноты
хранилище оповещает десятки раз в секунду. Перерисовывать на каждое
оповещение левую панель с полями ввода — лишняя работа и подтормаживание.
Поэтому `appView.ts` сравнивает «подпись» панели (что в ней видно)
с прошлой и перерисовывает, только если подпись изменилась.

**Почему без библиотеки (React и подобных).** Панели маленькие, а пианоролл —
холст, ему библиотека не нужна. Решим на этапе 3, когда появятся список
паттернов и стойка каналов.
