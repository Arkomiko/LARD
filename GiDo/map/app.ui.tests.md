# app/ui/tests/ — тесты интерфейса

**Что здесь.** Автоматические проверки логики на Vitest. Запуск — `npm test`
в папке `app/ui` или `scripts/test.ps1` для всех тестов сразу.

| Файл | Что проверяет |
| --- | --- |
| `model.test.ts` | создание и правки проекта, каналов, паттернов, нот; 5000 нот |
| `timeGrid.test.ts` | сетка (доли, такты, привязка) и правки группы нот: сдвиг, растяжение, квантизация |
| `undoHistory.test.ts` | история: лимит 100 шагов, отмена, повтор |
| `projectStore.test.ts` | хранилище: шаги истории, жесты, «несохранённое», выбор, выделение нот, настройки редактора |
| `tools.test.ts` | инструменты пианоролла и метод LARD: нажатия и протяжки мышью → изменения проекта |
| `viewport.test.ts` | окно просмотра и поиск нот под курсором, в рамке, под ластиком |
| `noteCommands.test.ts` | команды над выделением: удалить, копировать, вставить, дублировать, транспонировать |
| `hotkeys.test.ts` | горячие клавиши: русская раскладка, таблица без повторов, диспетчер, поля ввода |
| `projectFormat.test.ts` | project.json: сохранение и чтение, испорченные файлы |
| `formatVersions.test.ts` | миграции: старые файлы открываются новой программой |
| `autosaveScheduler.test.ts` | автосохранение по таймеру |
| `projectActions.test.ts` | новый, открыть, сохранить, вопросы про несохранённое, ошибки диска |
| `fakeHost.ts` | поддельная оболочка для тестов (не тест) |

**Как проверяются инструменты без экрана.** Окно просмотра настоящее, только
без холста: известный масштаб, известная прокрутка. Тест «нажимает» в точке
нужной ноты, «ведёт» мышь и «отпускает», а потом смотрит, что стало с нотами.

**Почему тесты отдельно от кода.** Так в `src/` лежит только то, что попадает
в программу, а всё проверочное — здесь.

**Чего здесь нет.** Тестов картинки на экране — ТЗ их не требует (п. 0.6).
