# presets/keymaps/ — раскладки горячих клавиш

**Что здесь.** Таблицы «команда — сочетание клавиш». Например, команде
`tool.draw` назначается клавиша. Раскладка по умолчанию повторяет FL Studio.

**Как это работает.** В программе три слоя: команда, таблица из этой папки
и диспетчер, который читает активную таблицу. Поэтому любую клавишу можно
переназначить, не трогая код.

**С чем связано.** Интерфейс `app/ui` загружает отсюда активную раскладку.

**Статус.** Пусто, этап 7.
