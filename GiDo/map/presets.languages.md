# presets/languages/ — языки интерфейса

**Что здесь.** Переводы интерфейса в формате JSON, один файл — один язык.
Встроены русский и английский. Английский — основа: если строки нет в другом
языке, она показывается по-английски.

**С чем связано.** Интерфейс `app/ui` берёт отсюда все надписи. Переводы
удобно править в `tools/translator/`.

**Статус.** Пусто, этап 7.
