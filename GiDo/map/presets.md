# presets/ — встроенные пресеты

**Что здесь.** Пресеты, которые идут вместе с программой. Пресет — это файл
с данными (JSON), а не код: чтобы добавить новую тему или язык, достаточно
положить файл в нужную папку. В коде ничего регистрировать не нужно.

| Папка | Что внутри | Описание |
| --- | --- | --- |
| `themes/` | цветовые темы | [presets.themes.md](presets.themes.md) |
| `languages/` | языки интерфейса | [presets.languages.md](presets.languages.md) |
| `workspaces/` | рабочие области (раскладки окон) | [presets.workspaces.md](presets.workspaces.md) |
| `keymaps/` | раскладки горячих клавиш | [presets.keymaps.md](presets.keymaps.md) |

**С чем связано.** Программа `app/` читает эти файлы при запуске.
Подпрограммы из `tools/` их редактируют. Моды типа «пресет» добавляют такие же
файлы через `mods/`.

**Статус.** Все папки пустые. Форматы файлов появятся на этапе 7.
