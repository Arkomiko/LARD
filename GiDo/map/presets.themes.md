# presets/themes/ — цветовые темы

**Что здесь.** Встроенные темы оформления. Тема задаёт значения
дизайн-токенов: цвета, размеры, скругления. Один файл — одна тема.

**С чем связано.** Интерфейс `app/ui` подставляет токены из выбранной темы.
Темы создаются в редакторе `tools/theme-editor/`.

**Статус.** Пусто, этап 7.
