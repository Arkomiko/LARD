# Корень репозитория

**Что здесь.** Верхний уровень проекта MiliPlain: папки с кодом и несколько
служебных файлов. Начинать знакомство с проектом — с этого файла.

| Что | Зачем | Описание |
| --- | --- | --- |
| `app/` | основная программа | [app.md](app.md) |
| `bridge/` | плагин MiliPlain Bridge для DAW | [bridge.md](bridge.md) |
| `tools/` | подпрограммы: редактор тем, перевод и другие | [tools.md](tools.md) |
| `presets/` | встроенные пресеты: темы, языки, раскладки | [presets.md](presets.md) |
| `mods/` | моды: учебные примеры и пользовательские | [mods.md](mods.md) |
| `scripts/` | служебные скрипты сборки | [scripts.md](scripts.md) |
| `GiDo/` | все тексты проекта | [GiDo.md](GiDo.md) |
| `.github/` | настройки страницы проекта на GitHub | [.github.md](.github.md) |
| `README.md` | описание, которое GitHub показывает на главной странице | — |
| `LICENSE` | лицензия программы | — |
| `.gitignore` | список того, что git не должен хранить | — |

**Почему тексты не лежат в корне.** Все документы собраны в `GiDo/`, чтобы
их не приходилось искать по всему проекту. Исключения — `README.md`
и `LICENSE`: GitHub ищет их именно в корне.

**Как части связаны.** Программа (`app/`) загружает пресеты из `presets/`
и моды из `mods/`. Мост (`bridge/`) ставится в DAW и общается с программой
по сети внутри компьютера. Подпрограммы (`tools/`) редактируют пресеты.
Как всё устроено подробно — в [../ARCHITECTURE.md](../ARCHITECTURE.md).
