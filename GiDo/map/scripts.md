# scripts/ — служебные скрипты

**Что здесь.** Скрипты PowerShell, чтобы не набирать длинные команды руками.
Запускаются из корня репозитория:

```
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

| Скрипт | Что делает |
| --- | --- |
| `build.ps1` | собирает всё: интерфейс, потом движок и оболочку. Результат — `app/shell/bin/Release/net10.0-windows/MiliPlain.exe` |
| `test.ps1` | запускает все тесты: интерфейса и движка |
| `dev.ps1` | режим разработки: Vite в отдельном окне и MiliPlain, который берёт интерфейс с него |

`-ExecutionPolicy Bypass` нужен потому, что Windows по умолчанию запрещает
запуск скриптов PowerShell. Параметр разрешает запуск только этого скрипта
и не меняет настройки системы.

**Важно при правке.** Скрипты сохранены в кодировке UTF-8 **с BOM**. Встроенный
в Windows 10 PowerShell 5.1 читает файл без BOM в старой кодировке, русские
комментарии превращаются в мусор, и скрипт перестаёт запускаться. VS Code
показывает кодировку в правом нижнем углу: должно быть «UTF-8 with BOM».
