# tools/ — подпрограммы

**Что здесь.** Подпрограммы — отдельные окна, каждое открывается само по себе
или из настроек MiliPlain. Делаются после основной программы (этап 9).

| Папка | Подпрограмма | Описание |
| --- | --- | --- |
| `theme-editor/` | редактор тем | [tools.theme-editor.md](tools.theme-editor.md) |
| `translator/` | инструмент перевода | [tools.translator.md](tools.translator.md) |
| `workspace-editor/` | редактор рабочих областей | [tools.workspace-editor.md](tools.workspace-editor.md) |
| `plugin-manager/` | Plugin Manager | [tools.plugin-manager.md](tools.plugin-manager.md) |

**С чем связано.** Подпрограммы редактируют файлы из `presets/` и пользуются
тем же устройством, что и основная программа: интерфейс на TypeScript в окне
оболочки на C#.

**Статус.** Все папки пустые, работа начнётся на этапе 9.
