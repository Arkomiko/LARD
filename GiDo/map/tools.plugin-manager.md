# tools/plugin-manager/ — Plugin Manager

**Что здесь.** Подпрограмма в духе Plugin Manager из FL Studio. Ищет плагины
VST3 и CLAP в папках компьютера, показывает их списком, позволяет отмечать
избранное и раскладывать плагины по категориям.

**Важное требование.** Плагин проверяется в отдельном процессе. Если он падает,
падает только проверка, а MiliPlain продолжает работать.

**С чем связано.** Через неё основная программа узнаёт, какие инструменты
и эффекты можно загрузить. Сам хостинг плагинов в версию 1.0 ядра не входит.

**Статус.** Пусто, этап 9.
