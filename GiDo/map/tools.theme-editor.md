# tools/theme-editor/ — редактор тем

**Что здесь.** Подпрограмма для создания и правки цветовых тем MiliPlain.
Пишется заново, код редактора тем из LARD не переносится.

**С чем связано.** Сохраняет темы в формате из `presets/themes/`. Готовая тема
сразу появляется в MiliPlain: пресеты — это данные, а не код.

**Статус.** Пусто, этап 9.
