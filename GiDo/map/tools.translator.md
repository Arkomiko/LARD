# tools/translator/ — инструмент перевода

**Что здесь.** Подпрограмма для перевода интерфейса на новые языки. Работает
как таблица «ключ — оригинал — перевод» и подсвечивает непереведённые строки.

**С чем связано.** Читает и пишет языковые файлы из `presets/languages/`.
Английский — основа и запасной вариант: строка без перевода показывается
по-английски.

**Статус.** Пусто, этап 9.
