# tools/workspace-editor/ — редактор рабочих областей

**Что здесь.** Подпрограмма для настройки рабочих областей, то есть раскладки
окон и панелей MiliPlain.

**С чем связано.** Сохраняет раскладки в `presets/workspaces/`.

**Открытый вопрос.** «Рабочую область» (раскладку окон) легко спутать
с «рабочим пространством» (`.mpln`, набором проектов). Как их называть в коде,
см. раздел «Ждут решения автора» в [../DECISIONS.md](../DECISIONS.md).

**Статус.** Пусто, этап 9.
