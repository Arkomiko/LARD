# Как запустить LARD

Инструкция для чистой машины. Рекомендуемая среда — **VS Code**, с неё и начните;
остальные разделы нужны, только если вы уже работаете в другой среде.

Все команды выполняются **из папки `source_dev`** — здесь лежит `package.json`.

---

## Что нужно поставить

| Программа | Зачем | Проверка |
| --- | --- | --- |
| [Node.js](https://nodejs.org/) 20 или новее | движок, на котором всё собирается | `node --version` |
| npm (ставится вместе с Node) | менеджер пакетов | `npm --version` |
| [Git](https://git-scm.com/) | история изменений | `git --version` |

Проверено на Node 24.19.0, npm 11.17.0, Git 2.55.0, Windows 10.

Отдельно ставить TypeScript, Vite или Electron не нужно — они приедут сами
вместе с зависимостями.

---

## Первый запуск (любая среда)

```sh
cd source_dev
npm install                     # зависимости приложения, один раз
npm install --prefix core/electron   # зависимости окна, один раз
```

`npm install` качает около гигабайта и занимает несколько минут — это нормально.

## Как запускать

```sh
cd source_dev
npm run dev:lard     # программа: сервер и её окно
npm run dev:theme    # редактор тем в своём окне
npm run dev          # всё сразу
```

Браузер ни одна из команд не открывает: LARD — программа с окном, и смотреть
на неё надо в окне. В браузере, кстати, **перетащить паттерн в Ableton
нельзя** — вкладке запрещено отдавать файлы другой программе.

Каждая команда поднимает две вещи: фоновый сервер, который раздаёт окну
исходники, и само окно. Если сервер нужен без окна — например, чтобы окно
перезапускать самому, — есть отдельная команда:

```sh
npm run dev:core    # только серверы: приложение на 3000, редактор тем на 3100
```

Порты закреплены жёстко. Занят — команда остановится и скажет об этом, а не
переедет на соседний: окно ищет содержимое по известному адресу.

## Как собирать

```sh
npm run build:lard     # LARD.exe
npm run build:theme    # [LARD] Theme Editor.exe
npm run build          # всё сразу
```

Результат — в `app_r/<версия>/Windows_Standalone/`: программа в корне папки,
редакторы в `Tools/`, рядом папки пресетов.

## VS Code — основной способ

1. **Файл → Открыть папку** и выбрать **`LARD-master`** целиком, а не `source_dev`.
   Это важно: папки `Theme`, `Language` и `Workspace` лежат в корне, и при
   открытии одного `source_dev` они окажутся вне проекта.
2. Открыть терминал: **Терминал → Создать терминал** (` Ctrl+` `).
3. Выполнить команды первого запуска (см. выше).

Полезные расширения — VS Code предложит их сам:

- **Biome** — форматирование и проверка стиля кода этого проекта.
- **ESLint** не нужен: проект использует Biome вместо него.

Отладка: **Выполнить → Начать отладку** (`F5`) и выбрать **LARD** — VS Code сам
поднимет сервер, откроет окно и подключит отладчик и к главному процессу, и к
странице внутри окна. Точки останова ставятся прямо в TypeScript. Для редактора
тем — конфигурация **Редактор тем**. Всё описано в `.vscode/launch.json`.

Запускать команды можно и без терминала: **Терминал → Выполнить задачу** —
там тот же список с русскими названиями (`.vscode/tasks.json`).

## JetBrains IntelliJ IDEA / WebStorm

1. **File → Open** и выбрать папку `LARD-master`.
2. IDE сама увидит `source_dev/package.json` и предложит установить зависимости —
   согласиться либо выполнить команды первого запуска в терминале IDE.
3. Задачи запуска появятся в панели **npm** (вид: `source_dev/package.json`).
   Нужны `start` и `build`.
4. Проверить, что в **Settings → Languages & Frameworks → Node.js** указан
   установленный Node, а рабочая папка задач — `source_dev`.

В IntelliJ IDEA Community поддержки JavaScript нет — понадобится WebStorm
либо IDEA Ultimate.

## Visual Studio 2026

Visual Studio ориентирована на C#/C++, и проект здесь открывается как набор
файлов, без своей системы сборки.

1. **File → Open → Folder** и выбрать `LARD-master`.
2. Открыть **View → Terminal**.
3. Выполнить команды первого запуска.

Отдельного файла решения (`.sln`) у проекта нет и не планируется: сборкой
занимаются npm и Vite. Если вам удобнее Visual Studio — работать можно,
но никаких преимуществ перед VS Code здесь нет.

## Без IDE, из обычного терминала

Годится любой терминал: PowerShell, Windows Terminal, Git Bash.

```sh
cd "путь\до\LARD-master\source_dev"
npm install
npm install --prefix core/electron
npm run dev:lard
```

## Проверка, что всё цело

```sh
cd source_dev
npx tsc --noEmit -p app/tsconfig.json   # проверка типов, должно быть пусто
npm test                                # тесты всех пакетов, должны быть зелёные
npm run build:lard             # сборка, должна пройти без ошибок
```

## Частые ошибки

**`npm install` падает на загрузке Electron, ошибка TLS или SSL**

Загрузка идёт с GitHub и иногда обрывается. Просто повторите команду —
обычно помогает со второго раза. Если не помогает, скачайте архив вручную:
`https://github.com/electron/electron/releases` → `electron-v31.6.0-win32-x64.zip`,
распакуйте в `source_dev/core/electron/node_modules/electron/dist/`.
Зеркало `npmmirror.com` из России недоступно, пробовать его бесполезно.

**Браузер пишет `ERR_CONNECTION_REFUSED` на localhost:3000**

Сервер не запущен либо ещё поднимается. Убедитесь, что терминал с
`npm run dev:lard` работает и в нём нет ошибок. Первый запуск занимает до
полуминуты.

**Окно LARD открывается белым**

Обычно сервер приложения не запущен — проверьте первый терминал.

**Не переносится паттерн в Ableton**

Проверьте, что LARD запущен своим окном, а не открыт во вкладке браузера.
Из браузера это невозможно.

**Правка темы или языка не видна**

Проверьте, что открыта папка `LARD-master`, а не `source_dev`, и что файл
лежит в корневой `Theme/` или `Language/`.

**Порт 3000 занят**

Другая программа уже слушает этот порт. Закройте её либо поменяйте порт
в `source_dev/app/vite.config.mts` (поле `server.port`).

## Куда что положено

| Папка | Что внутри |
| --- | --- |
| `source_dev/app/` | основное приложение: пианоролл, интерфейс |
| `source_dev/app/src_Tools/` | исходники редакторов: тем (готов), языков, рабочих областей |
| `source_dev/core/packages/` | библиотеки: работа с песней, треками, MIDI, звуком |
| `source_dev/core/electron/` | оболочка окна программы и мост к системе |
| `source_dev/core/tools_shell/` | оболочка окна редакторов |
| `source_dev/core/src/` | общее ядро: формат пресетов, цвет, генератор тем |

| `source_dev/core/scripts/` | служебные скрипты, в том числе сборка |
| `source_dev/Tools_presets/` | заготовки пресетов: темы, языки, раскладки |
| `app_r/` | готовые сборки |
| `docs/` | документация проекта |
