# Темы LARD

Каждый файл `*.json` в этой папке — отдельная тема. Она появляется в
настройках сама: **Settings → Theme**. Регистрировать её в коде не нужно.

Проще всего собирать тему в редакторе: он считает цвета по правилам и следит
за контрастом.

```bash
npm run dev:theme
```

Подробности — в [README редактора](../../app/src_Tools/src_Theme/README.md).
Ниже — про сам формат файла, если править его руками.

## Как сделать свою тему

1. Скопируйте любой файл, например `dark.json`, под новым именем — скажем,
   `mytheme.json`. Имя файла станет внутренним именем темы.
2. Поменяйте цвета.
3. Сохраните. При запущенном `npm run dev:lard` картинка обновится сразу,
   перезапускать ничего не нужно.

Задавать все поля необязательно. Всё, что не указано, берётся из тёмной
темы. Так что рабочая тема может состоять из трёх строк:

```json
{
  "label": "Мой эксперимент",
  "themeColor": "#ff7f00",
  "editorBackgroundColor": "#101010"
}
```

Цвет пишется в любом виде, который понимает CSS: `#rrggbb`, `rgba(...)`,
`hsl(...)`.

## Поля

| Поле | Что красит |
| --- | --- |
| `label` | Подпись в списке тем. Не цвет. |
| `isLightContent` | `true` — тема тёмная, текст на ней светлый. Влияет на расчёт контраста рамок нот. |
| `font` | Основной шрифт интерфейса |
| `monoFont` | Моноширинный шрифт |
| `canvasFont` | Шрифт подписей внутри пианоролла |
| `themeColor` | Акцент интерфейса и цвет ноты по умолчанию |
| `onSurfaceColor` | Текст и значки поверх акцентного цвета |
| `textColor` | Основной текст |
| `secondaryTextColor` | Второстепенный текст |
| `tertiaryTextColor` | Самый бледный текст |
| `dividerColor` | Разделительные линии |
| `popupBorderColor` | Рамка всплывающих окон и меню |
| `darkBackgroundColor` | Самый тёмный фон: панели, заголовки |
| `backgroundColor` | Основной фон окна |
| `secondaryBackgroundColor` | Фон полей ввода и кнопок |
| `editorBackgroundColor` | Фон полотна редактора |
| `editorGridColor` | Линии тактов — жирная сетка |
| `editorSecondaryGridColor` | Линии долей — мелкая сетка |
| `pianoKeyBlack` | Чёрные клавиши слева |
| `pianoKeyWhite` | Белые клавиши слева |
| `pianoWhiteKeyLaneColor` | Дорожка белой клавиши в сетке |
| `pianoBlackKeyLaneColor` | Дорожка чёрной клавиши в сетке |
| `pianoHighlightedLaneColor` | Дорожка ноты, входящей в выбранную тональность |
| `pianoLaneEdgeColor` | Горизонтальные границы дорожек |
| `ghostNoteColor` | Ноты соседних дорожек (призраки) |
| `recordColor` | Кнопка записи |
| `cursorColor` | Курсор воспроизведения |
| `shadowColor` | Тени |
| `highlightColor` | Подсветка под курсором мыши |
| `greenColor` | Служебный зелёный: успех, соло |
| `redColor` | Служебный красный: ошибка |
| `yellowColor` | Служебный жёлтый: предупреждение |
| `cornerRadius` | Скругление карточек, диалогов и панелей. Значение как в CSS: `0.5rem`, `8px`, `0` |
| `controlCornerRadius` | Скругление кнопок, полей ввода и мелких элементов |
| `generator` | Настройки, которыми тема собрана в редакторе. Не цвет — приложение его не читает |

## Встроенные темы

| Файл | Что это |
| --- | --- |
| `dark.json` | Тёмная по умолчанию |
| `light.json` | Светлая |
| `windows10.json` | Стиль Windows 10 / UWP: системный синий `#0078d4`, шрифт Segoe UI |
| `flstudio.json` | Палитра FL Studio 2026, снятая пипеткой со скриншотов официального руководства |

`windows10.json` легко превратить в вариант Xbox — замените `themeColor` и
`cursorColor` на фирменный зелёный `#107c10`.

## Поле `generator`

Темы, собранные в редакторе, несут ещё и настройки, которыми их собрали:

```json
{
  "label": "Мой неон",
  "generator": {
    "mode": "fast",
    "baseColor": "#4d6bff",
    "harmony": "analogous",
    "coloredBackground": false,
    "moreAccents": false
  },
  "themeColor": "#4d6bff"
}
```

Приложению это поле не нужно — оно читает готовые цвета. Нужно оно редактору:
открыв такую тему, он вернётся в тот же режим с теми же крутилками, а не
покажет голый список цветов. У темы, написанной руками, поля просто нет — и
редактор откроет её в разработчиковом режиме.
