# Рабочие области LARD

Каждый файл `*.json` в этой папке — отдельная раскладка интерфейса: какие
панели видны и какого они размера. Файл появляется в настройках сам,
регистрировать его в коде не нужно — ровно как тему в [`../Theme`](../Theme).

Устройство взято из FL Studio: там раскладка — это именованный набор окон
(меню **View → Arrange windows**), любое окно показывается или прячется, и
любую раскладку можно сохранить своей. Отличие одно: в LARD это не плавающие
по столу окна, а области одного окна. LARD работает рядом с Ableton Live, и
разлетающиеся окна ему только мешали бы.

## Как сделать свою раскладку

1. Скопируйте `lard.json` под новым именем — оно станет именем раскладки.
2. Поменяйте, что нужно.
3. Сохраните. При запущенном `npm run dev:lard` ничего перезапускать не надо.

Задавать все поля необязательно: недостающее берётся из базовой раскладки.
Рабочий файл может состоять из двух строк:

```json
{
  "label": "Только пианоролл",
  "panels": {
    "patternList": { "visible": false },
    "trackList": { "visible": false }
  }
}
```

Панель, у которой указано только одно поле, второе сохраняет: скрытая
`patternList` не теряет свою ширину и вернётся с ней же.

## Поля

| Поле | Что задаёт |
| --- | --- |
| `label` | Подпись в списке раскладок |
| `view` | Раздел при старте: `track` (пианоролл), `arrange`, `tempo` |
| `panels` | Панели по имени: `visible` — видна ли, `size` — её размер |

`size` пишется числом (пиксели) или строкой с процентом — `"40%"`. Это размер
самой панели, а не того, что остаётся редактору.

## Панели

| Имя | Что это | Ближайшее в FL Studio |
| --- | --- | --- |
| `patternList` | список паттернов слева | Playlist |
| `trackList` | стойка инструментов справа | Channel Rack |
| `eventList` | список событий | Event editor |
| `controlPane` | полоса автоматизации под пианороллом | — |
| `navigation` | верхняя панель вкладок | Toolbars |
| `toolbar` | панель инструментов редактора | Toolbars |
| `transport` | транспорт: воспроизведение, запись | Transport panel |

## Встроенные раскладки

| Файл | Что это |
| --- | --- |
| `lard.json` | Раскладка LARD по умолчанию |
| `flstudio.json` | В духе FL Studio: боковые панели шире, полоса автоматизации ниже |
