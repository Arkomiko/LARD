# Редактор языков — `[LARD] Language Editor`

Исходники отдельного приложения для правки переводов.

Работает на общем ядре `source_dev/core/`, читает и пишет файлы
из папки `source_dev/Tools_presets/Language/`.

Состояние: **не начато**. План — в `task.md`, этап 6.2.

Пока перевод правится вручную: один файл на язык, недостающие строки
автоматически берутся из английского.
