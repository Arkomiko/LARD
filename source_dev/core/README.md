# `@lard/core` — общее ядро LARD

Здесь лежит то, что нужно **и** основному приложению, **и** редакторам из
[`app/src_Tools`](../app/src_Tools): формат пресетов и их загрузка.

Пресетов три вида, и устроены они одинаково: папка в `Tools_presets`, в ней
файлы, имя файла — имя пресета, содержимое — неполное описание поверх базового.

| Папка | Что за пресет | Кто правит |
| --- | --- | --- |
| [`Theme/`](../Tools_presets/Theme) | цвета интерфейса | `app/src_Tools/src_Theme` |
| [`Language/`](../Tools_presets/Language) | переводы | `app/src_Tools/src_Language` |
| [`Workspace/`](../Tools_presets/Workspace) | раскладка панелей | `app/src_Tools/src_Workspace` |

## Зачем отдельный пакет

Каждый редактор читает и пишет свой вид пресетов, но понимать формат все
обязаны одинаково. Без общего ядра редактор тем хранил бы собственную копию
списка цветов, и стоило бы добавить в тему одно поле — редактор о нём бы не
узнал. Поэтому формат и правила слияния лежат в одном месте, а приложение и
редакторы им пользуются.

## Что внутри

| Файл | Что делает |
| --- | --- |
| `src/presets/presetFolder.ts` | общий разбор папки пресетов: имя из пути, наложение файла на базу, откат на запасной |
| `src/theme/Theme.ts` | поля темы и базовая тёмная тема |
| `src/theme/loadThemes.ts` | сборка тем из файлов папки |
| `src/language/Language.ts` | что такое перевод и запасной язык |
| `src/language/loadLanguages.ts` | сборка словарей: неполный перевод добирает английский |
| `src/language/localeRules.ts` | подбор языка по локали браузера |
| `src/workspace/Workspace.ts` | поля рабочей области и базовая раскладка |
| `src/workspace/loadWorkspaces.ts` | сборка раскладок из файлов папки |

## Чего здесь нет

**Чтения файлов.** Ядро не знает ни про React, ни про Electron, ни про Vite: в
приложении папку разворачивает сборщик (`import.meta.glob`), в редакторах —
файловая система. Сюда передают уже прочитанные файлы, и ядро остаётся
пригодным для обоих случаев.

**Музыки.** Песня, дорожки, события и MIDI — это `@signal-app/core` из
[`packages/core`](packages/core), унаследованный от signal. Два разных
«ядра» с похожими именами: это — про пресеты, то — про музыку.
