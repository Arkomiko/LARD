# Оболочка окна для инструментов

Одно окно Electron на все редакторы из `Tools`. Инструменты отличаются только
содержимым, поэтому окно, поведение ссылок и запуск у них общие.

Что показать, задаётся снаружи:

```sh
node launch.cjs http://127.0.0.1:3100/ "[LARD] Theme Editor"
```

Без адреса оболочка грузит `renderer/index.html` рядом с собой — так она будет
работать в собранном виде, когда сборка положит туда файлы инструмента.

Запускать только через `launch.cjs`: терминал VS Code выставляет
`ELECTRON_RUN_AS_NODE=1`, и от неё нужно избавиться до старта — иначе Electron
поднимется как обычный Node и окна не будет.
